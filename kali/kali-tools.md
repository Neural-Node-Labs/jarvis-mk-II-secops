Here's a quick rundown of what each tool does:

| Tool | Purpose |
|---|---|
| **`kali-defaults`** | Just applies Kali's default settings (theme, configs, branding) — lightweight, mostly cosmetic |
| **`kali-autopilot`** | A scripting engine for automated attack sequences — lets you create and replay attack scenarios |
| **`nmap`** | Network scanner — port scanning, service detection, OS fingerprinting |
| **`hydra`** | Password brute-forcing tool — attacks login services (SSH, FTP, HTTP, etc.) |
| **`john`** (John the Ripper) | Password hash cracking — offline cracking of password hashes |
| **`metasploit-framework`** | Exploitation framework — find, test, and execute exploits against targets |
| **`sqlmap`** | Automated SQL injection detection and exploitation |
| **`burpsuite`** | Web application security testing — intercepts and modifies HTTP traffic |
| **`aircrack-ng`** | WiFi security auditing — packet capture, WEP/WPA cracking |
| **`wireshark`** | Network packet analyzer — deep inspection of network traffic |

If you just want to **prove this is Kali**, `kali-defaults` is the quickest win. If you want something **functional** for actual security work, pick one from the list below that fits your use case.
